A sales-analysis-mini-project

Mini Project Task: Sales Analysis

Goal: Analyze sales data and present insights.
Step-by-Step Task (using Python or Excel)

1. Data Cleaning
Check for missing values
Convert dates if needed
Remove duplicates (if any)

2. Key Questions to Answer
What is the average sales per customer?
Which month has the highest total sales?
Who are the top 5 customers by total spend?
Create a bar chart of sales by region (or product type, if applicable)

3. Visualize
Use Excel charts or Seaborn/Matplotlib:
Bar chart of sales per region/customer
Line chart of monthly sales trend

4. Summarize Findings
Example:
“Most sales occur in July.”
“Top 5 customers account for 40% of total revenue.”
“Region X has the lowest sales – potential area to improve.”
